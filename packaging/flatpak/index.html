Purple Pen — Flatpak Repository

Purple Pen is course setting software for orienteering. This page hosts a Flatpak repository for Linux.

Install

flatpak remote-add --user --if-not-exists purplepen \
  https://misacek007.github.io/PurplePen/index.flatpakrepo

flatpak install --user purplepen org.purplepen.PurplePen

Update

flatpak update

Run

flatpak run org.purplepen.PurplePen

Inspect installed files

# Show install path, then list its contents
flatpak info -l org.purplepen.PurplePen
ls $(flatpak info -l org.purplepen.PurplePen)/files/

# Browse files inside the sandbox
flatpak run --command=ls org.purplepen.PurplePen /app/bin/
flatpak run --command=ls org.purplepen.PurplePen /app/share/

# Show app metadata and permissions
flatpak info org.purplepen.PurplePen
flatpak info -m org.purplepen.PurplePen
